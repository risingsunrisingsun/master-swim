# ADR-0001: 모든 숫자는 결정론적 공식에서 나온다

- 상태: 채택
- 날짜: 2026-07-26

## 맥락

앱이 훈련·식단을 처방한다. 처방의 근거로 세 가지 후보가 있었다.

1. 매번 LLM 이 생성
2. 코드에 박힌 공개 공식
3. 팀 실측 데이터 회귀

동호회 회원 20~30명이 실제 훈련에 쓰는 도구다. 같은 입력에 다른 처방이 나오면
신뢰가 무너지고, 틀렸을 때 어디가 틀렸는지 추적할 수 없다. 3번은 표본이 부족하다
— 30명을 종목×연령대로 쪼개면 칸당 1~2명이다.

## 결정

**2번.** 모든 계산은 순수 함수로 코드에 둔다. LLM 을 호출하지 않는다.
계산 로직은 DOM·저장소·네트워크를 참조하지 않는다.

## 결과

**정직하게 계산되지 않는 것은 만들지 않는다.** 특히 신장·윙스팬·체중·골격근량으로
기록을 예측하는 검증된 공식은 존재하지 않는다. 엘리트 집단 상관연구는 있으나
개인의 인과 예측이 아니고, 근육량 증가는 추진력과 항력을 동시에 올려 부호가 상쇄된다.

따라서 체성분 기능은 **예측이 아니라 진단**으로 간다. 보조로 두는 슬라이더는
물리식 `v ∝ (P/A)^⅓` 를 공식과 오차범위를 드러낸 채 제공하며, 점 추정치를 내지 않는다.

부수적으로 네트워크 요청이 0회가 되어 오프라인 동작이 공짜로 따라온다.
수영장에 와이파이가 없다는 제약과 맞아떨어진다.
