# ADR-0003: 목표 레이스 페이스를 모든 세트의 기준점으로 삼는다

- 상태: 채택
- 날짜: 2026-07-26

## 맥락

훈련 페이스에는 기준점이 필요하다. 통상적인 선택지는 임계속도(CSS)다. 그런데
CSS 는 400m/200m 두 거리로 산출하는데 이 앱의 최대 지원 거리는 100m다.
**기준점이 없다.**

한편 전 종목이 25/50/100 이라 사용자는 전원 스프린터이고, 사용자가 목표기록을
입력하는 것이 이 앱의 전제다.

## 결정

**목표기록에서 뽑은 25m당 페이스**를 기준점으로 삼는다 (USRPT 방식).

```
목표기록 = (첫 구간: p − 다이빙이득) + (나머지: p × (n−1)) = p × n − 다이빙이득
⇒ p = (목표기록 + 다이빙이득) / n
```

대회 첫 구간은 다이빙으로 출발하지만 훈련 반복은 벽 푸시오프로 출발한다.
보정하지 않으면 목표 페이스가 실제보다 빠르게 잡혀 지킬 수 없는 세트가 나온다.

## 결과

별도 테스트 수영이 필요 없다. 목표기록 입력만으로 즉시 계산되고, 스프린트 종목에
적합하며, "목표 달성용 훈련법"이라는 요구와 정확히 일치한다.

대가로 **목표가 비현실적이면 세트가 전부 붕괴한다.** 목표 검증이 선택이 아니라
필수 부품이 된다. 검증은 연령대별 분위수 표 대비 위치로 하며(3차), 그전까지는
수영계 통용 절대 구간으로 대체한다.

USRPT 는 부수적으로 검증기를 하나 준다 — **실패율 자체가 목표가 이르다는 측정된
증거다.** 앱이 추측할 필요 없이 물속에서 답이 나온다. 다만 이 때문에 세트 실패는
정상 동작이므로, 실패 기록은 코치만 열람한다. 팀 전체에 공개되면 회원이 목표를
낮게 잡기 시작하고 기준점 자체가 망가진다.
