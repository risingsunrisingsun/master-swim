# ADR-0008: 라이트 테마 하나만 지원한다

- 상태: 채택
- 날짜: 2026-07-26

## 맥락

처음에는 `prefers-color-scheme: dark` 분기를 두고 두 테마를 다 만들었다. 그런데
폰을 다크 모드로 쓰는 회원에게는 앱 전체가 어둡게 떴고, "너무 어둡다"는 피드백이
왔다.

원인은 버그가 아니라 결정이었다 — OS 설정을 따라가게 만들었으니 따라간 것이다.
문제는 **두 테마를 다 만들면 둘 다 어중간해진다**는 쪽이었다. 이 앱의 기준
디자인은 흰 카드 기반의 밝은 화면이고, 다크 판은 그것을 기계적으로 뒤집은 것에
가까웠다.

## 결정

**라이트 하나만 지원한다.** `color-scheme: light` 를 선언하고
`prefers-color-scheme` 분기를 전부 없앤다. 팀 로고의 파랑(`#0868e8`)만 강조색으로
살린다.

차트 마크 색은 UI 강조색과 **역할이 달라 토큰을 따로 둔다** — 마크는 표면 대비
명도 밴드를, UI 텍스트는 본문 대비를 만족해야 한다. 라이트 표면에서는 두 값이
같아도 되지만, 역할이 다르다는 사실은 토큰으로 남긴다.

## 결과

다크 모드 사용자에게는 밝은 화면이 강제된다. 야간 수영장 탈의실에서 눈이 부실
수 있고, 그건 실제 비용이다. 다시 다크를 넣는다면 밝은 판을 뒤집는 것이 아니라
**어두운 표면에 대해 다시 고른 값**으로 만들어야 한다 — 마크 색은 어두운 표면용
명도 밴드(OKLCH L 0.48~0.67)를 따로 통과해야 하고, `#6aa8ff` 는 텍스트로는
맞지만 마크로는 그 밴드를 벗어난다.

부수적으로 CSS 가 짧아지고, 모든 회원이 같은 화면을 본다 — 스크린샷으로 서로
문의할 때 이게 도움이 된다.
