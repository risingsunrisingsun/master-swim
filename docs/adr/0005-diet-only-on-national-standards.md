# ADR-0005: 식단은 국가 기준 위에서만 계산한다

- 상태: 채택
- 날짜: 2026-07-26

## 맥락

식단을 붙이기로 했다. LLM 을 쓰지 않기로 했으므로(ADR-0001) 메뉴를 결정론적으로
만들어야 하는데, 그냥 음식 이름을 늘어놓으면 근거가 없는 창작이 된다.

다행히 국가가 알고리즘까지 만들어 뒀다 — **한국인 영양소 섭취기준(KDRIs)의
식사구성안**은 에너지 수준별로 식품군 섭취횟수를 제시하고, 식품군마다 1회 분량의
열량과 대표식품을 정해 두었다.

## 결정

계산은 이 순서로만 내려간다.

```
기초대사량(Mifflin-St Jeor) × 활동계수 1.4
  + 수영 소모(MET × 3.5 × 체중 / 200 × 분)
  → 식품군별 섭취횟수
  → 식품군 대표식품
```

식품군 1회 분량 열량은 식사구성안 값을 그대로 쓴다 — 곡류 300, 고기·생선·달걀·콩류
100, 채소류 15, 과일류 50, 우유·유제품류 125, 유지·당류 45 kcal.

훈련일/휴식일 두 가지만 만든다. 단백질 목표는 ACSM/IOC 범위 안에서 훈련일 1.6,
휴식일 1.2 g/kg 을 쓴다.

## 결과

**채소·과일·유지는 거의 고정이고 곡류가 완충 역할을 한다.** 채소는 열량이 아니라
미량영양소 목적이라 에너지와 무관하게 7회로 두고, 단백질군은 체중에서, 곡류는
*남은 열량*에서 나온다. 그래서 훈련일에 늘어나는 것은 주로 곡류다.

**메뉴를 지정하지 않는다.** 식품군별 횟수와 대표식품만 보여준다. 개인의 질환·알레르기·
종교·식성을 모르는 상태에서 "저녁에 이걸 드세요"라고 말하지 않기 위해서다.

이 화면은 키·체중을 요구하므로 **신체 데이터 규칙을 그대로 따른다** — 입력은
선택이고, 없으면 식단만 잠기며, 값은 기기를 벗어나지 않는다(ADR-0002).
