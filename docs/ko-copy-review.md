# 한국어 문구 감수

화면에 실제로 뜨는 문구만 감수했다. `methods.ts` 의 `purpose`·`principle`·`cautions` 와
`CATEGORY_LABEL` 은 지금 어느 화면에서도 렌더링되지 않으므로 제외했다.

각 항목은 **위치 / 현재 / 제안 / 이유** 순이다. 체크박스에 표시하면서 보면 된다.

## 0. 어색함의 원인 세 가지

번역투 문장이 흩어져 있다기보다, 세 가지가 화면 안에서 부딪힌다.

1. **문체 혼용** — 한 카드 안에서 `~한다`(해라체)와 `~습니다`(합쇼체)가 섞인다.
   이게 가장 크다. §1.
2. **용어 불일치** — 같은 것을 화면마다 다르게 부른다(데센딩/디센딩, 지상훈련/육상/뭍). §2.
3. **직역투와 조사 오용** — 주로 어록과 메뉴 부제. §3, §4.

## 1. 문체 혼용 — 제안 A 로 반영 완료

지금 화면은 이렇게 갈린다.

| 화면 | 해라체 (`~한다`) | 합쇼체 (`~습니다`) |
| --- | --- | --- |
| 지상훈련 | `why`·`cue` 전부 (`dryland.ts:52,57,86,...`) | 안내문 (`view.ts:223-226, 231-232`) |
| 훈련·식단 | 끼니 힌트 (`nutrition.ts:177,202`) | 식단 설명 (`view.ts:355-362`) |
| 수영용어 | `short`·`detail` 전부 (`terms.ts:40-306`) | 퀴즈 총평 (`terms.ts:384-387`) |

같은 화면을 스크롤하다 "…뜨는 순간 세트를 끝낸다." 바로 아래에서
"…통증이 있으면 강화가 아니라 진료가 먼저입니다." 를 만난다. 이게 어색함의 절반이다.

**제안 A (권장)** — 기준을 *말 거는 상대*로 나눈다.

- 개념·원리를 **서술**하는 글 → 해라체 유지 (`terms.short/detail`, `dryland.why`)
- 사용자에게 **시키는/알리는** 글 → 합쇼체 (`dryland.cue`, `nutrition` 끼니 힌트, 모든 버튼·안내·판정)

사전은 사전 문체로, 코치의 말은 존댓말로. 지금 코드에서 바꿀 대상은
`dryland.ts` 의 `cue` 15개와 `nutrition.ts` 의 힌트 2개뿐이다.

**제안 B** — 전부 합쇼체. 가장 안전하지만 용어집 300줄이 길어지고 사전 맛이 사라진다.

- [x] **A 로 간다.**

### 1-1. 반영 범위

| 대상 | 개수 | 비고 |
| --- | --- | --- |
| `dryland.ts` 의 `cue` | 24 | 감수 초안에 15개로 적었던 것은 세는 실수였다 |
| `nutrition.ts` 끼니 힌트 | 2 | `과일 + 우유` → `과일과 우유` 도 함께 |
| `methods.ts` 의 `note` | 2 | 훈련 화면에 뜨는 해라체 문장. 아래 1-3 참조 |

바꾸지 않은 것: `terms.ts` 의 `short`·`detail`, `dryland.ts` 의 `why`.
개념을 서술하는 글이므로 해라체를 유지한다 — 이것이 제안 A 의 기준이다.

바뀐 예:

| 전 | 후 |
| --- | --- |
| …승모근이 대신 일하는 것이다. | …승모근이 대신 일하고 있는 겁니다. |
| 허리가 바닥에서 뜨는 순간 세트를 끝낸다. | 허리가 바닥에서 뜨는 순간 세트를 끝내세요. |
| 엉덩이를 들지도 떨어뜨리지도 않는다. 숨을 참으면 안 된다. | 엉덩이를 들지도 떨어뜨리지도 마세요. 숨을 참으면 안 됩니다. |
| 엎드려 팔다리를 든다. 목을 젖히지 않는다 — 시선은 바닥. | 엎드려 팔다리를 듭니다. 목은 젖히지 마세요 — 시선은 바닥. |

### 1-2. 감수 초안에 없었으나 함께 고친 것

- [x] **`methods.ts` 의 해라체 note 2개** — 훈련 화면 세트 줄에 그대로 뜬다.
  `1번은 +2초에서 시작해 매 반복 당긴다` → `…당깁니다`,
  `묶음마다 시작 페이스를 당긴다` → `…당깁니다`.
  나머지 note 는 전부 명사구(`완전 회복 2분`)라 손대지 않았다.

- [x] **`methods.ts` 테스트 세트 note 의 겹말** — `다이빙 스타트, 구간 기록 기록`
  → **`다이빙 스타트, 구간 기록까지 측정`**. '기록 기록'이 그대로 화면에 떴다.

- [x] **박스 점프 `cue` 의 `**` 가 화면에 그대로 찍히던 문제**
  `view.ts` 에서 `why` 는 `bold()` 를 거치는데 `cue` 는 `escapeHtml()` 만 거쳐,
  `뛰어오르되 **내려올 때는 걸어서** 내려옵니다` 가 별표째 보였다.
  `cue` 도 `bold()` 를 거치게 했다(`bold` 는 이스케이프 먼저라 안전하다).

## 2. 용어 불일치 — 반영 완료

- [x] **데센딩 → 디센딩**
  `methods.ts:160` 세트 이름이 `데센딩`, `terms.ts:177` 용어집 표제어는 `디센딩`.
  퀴즈에서 '디센딩'을 가르쳐 놓고 주간 플랜에는 '데센딩'이 뜬다.
  동호회·연맹 표기는 **디센딩**. `methods.ts:36,160,166` 세 곳.

- [x] **지상훈련 / 육상 / 뭍 → 지상훈련**
  같은 기능을 세 이름으로 부른다.
  - `view.ts:139` 메뉴 타일 `지상훈련 세트`
  - `view.ts:140`·`main.ts:395` 부제 `영법별로 뭍에서 만들 것`
  - `view.ts:223` 같은 화면 안내문 `주간 플랜에 들어가는 육상 세트는…`
  화면 문구는 **지상훈련**으로 통일하고, `육상`은 코드 주석·내부 용어로만 남긴다.
  (`view.ts:223` → `주간 플랜에 들어가는 지상훈련 세트는…`)

- [x] **레이스페이스 / 레이스 페이스**
  `methods.ts:80,99` 세트 이름은 붙여서 `레이스페이스 25`,
  `terms.ts:153`·`plan.ts` 제목은 띄어서 `레이스 페이스`.
  같은 화면(하루 세션)에 둘 다 뜬다. **`레이스 페이스 25`** 로 띄운다.

- [x] **언더워터 / 잠영**
  세트 이름은 `언더워터 · 브레이크아웃`인데 그 아래 note 는 `잠영 10m 목표`
  (`methods.ts:296-299`). 용어집 표제어도 `언더워터 (돌핀킥)`(`terms.ts:127`) 라
  '잠영'이라는 말은 어디에서도 설명되지 않는다.
  → note 를 `언더워터 10m 목표` 로 바꾸거나, 용어집 표제어를 `언더워터 (잠영·돌핀킥)` 로.
  **택한 쪽: note 를 `언더워터 …` 로.** 세트 이름 바로 아래에 붙는 줄이라 같은 말로
  이어지는 편이 낫고, 퀴즈 보기로 쓰이는 표제어가 길어지지 않는다.
  `methods.ts` 의 `cautions` 에 남은 '잠영'은 화면에 뜨지 않으므로 그대로 뒀다.

## 3. 화면 문구 — 직역투·조사·비문 (반영 완료)

- [x] **`main.ts:379`** 메뉴 부제
  현재 `무엇을 하시겠습니까`
  → **`오늘은 무엇을 해볼까요`**
  *의문문인데 물음표가 없고, 은행 키오스크 말투다.*

- [x] **`view.ts:140` / `main.ts:395`** 지상훈련 부제
  현재 `영법별로 뭍에서 만들 것과 영상` / `영법별로 뭍에서 만들 것`
  → **`영법별 지상 보강운동과 참고 영상`** / **`영법별 지상 보강운동`**
  *'만들 것'에 목적어가 없어 무엇을 만드는지 읽히지 않는다. '뭍'은 문어체.*

- [x] **`view.ts:132` vs `main.ts:383`** 같은 화면 설명이 두 가지
  타일 `목표기록에서 주간 플랜과 식단을 만듭니다`
  부제 `목표 페이스에서 주간 플랜과 식단을 만듭니다`
  → 둘 다 **`목표기록으로 주간 플랜과 식단을 만듭니다`**
  *'A에서 B를 만들다'의 '에서'는 재료 조사로 어색하다. 타일을 눌러 들어간 화면의
  부제가 타일과 다른 말을 하는 것도 문제.*

- [x] **`view.ts:144`** 수영용어 부제
  현재 `코치 말을 알아듣는 데 필요한 것 + 퀴즈`
  → **`코치의 말을 알아듣는 데 필요한 용어 · 퀴즈`**
  *'코치 말'은 낮춤으로 읽힌다. '+' 는 문장 안에서 튄다(다른 곳은 전부 `·`).*

- [x] **`view.ts:434`** 휴식일
  현재 `회복이 다음 세션의 질을 정합니다.`
  → **`회복이 다음 훈련의 질을 좌우합니다.`**
  *'질을 정한다'는 determines 직역.*

- [x] **`view.ts:513`** 주간 합계
  현재 `이번 주  계획 2,400m / 입력 6,000m`
  → **`이번 주  계획 2,400m / 내가 적은 양 6,000m`**

- [x] **`view.ts:355`** 식단 열량 줄

- [x] **`main.ts:177`** 기록 입력 되읽기

## 4. 어록 번역 (`quotes.ts`)

### 4-1. 카드마다 높임이 달라진다

지금 존댓말: 러데키 · 드레슬 · 소프 · 셰스트룀 · 매킨토시 · 무삼바니 · 펠프스
지금 반말: 황선우 · 김우민 · 이케에 · 밀라크 · 박태환

황선우·김우민·박태환은 **한국어 원문 인용**이라 손대면 안 된다. 하지만
이케에(일본어)·밀라크(영어)는 번역문이므로 존댓말로 옮길 수 있다.
번역 카드만 존댓말로 모으면 "원문이 한국어면 그대로"라는 규칙(`quotes.ts:51`)과도 맞는다.

- [ ] 번역 카드는 존댓말로 통일한다 / [ ] 지금대로 둔다

### 4-2. 문장별

- [ ] **러데키 `108`**
  원문 `You just need to win your race. And winning your race means falling in love with the process, not the podium.`
  현재 `자기 레이스에서 이기면 됩니다. 그리고 자기 레이스에서 이긴다는 건 시상대가 아니라 과정을 사랑하게 되는 것입니다.`
  → **`자기 레이스에서 이기면 됩니다. 그리고 자기 레이스에서 이긴다는 건, 시상대가 아니라 그 과정을 사랑하게 된다는 뜻입니다.`**
  *'~하게 되는 것입니다'가 늘어진다.*

- [ ] **드레슬 `121`**
  원문 `I come to practice every day with the mindset that I'm there to get better.`
  현재 `나는 매일 오늘 더 나아지러 왔다는 마음으로 훈련에 나갑니다.`
  → **`나는 매일 더 나아지려고 이 자리에 왔다는 마음으로 훈련에 나섭니다.`**
  *'매일 오늘'은 중복이고 원문에 없다. '나아지러 왔다'는 비문에 가깝다.*

- [ ] **소프 `133`**
  원문 `Every time I go into a swimming race I try to get the best out of myself.`
  현재 `경기에 들어갈 때마다 나는 내 안에서 가장 좋은 것을 꺼내려고 합니다.`
  → **`레이스에 들어갈 때마다 나는 내가 가진 최고를 끌어내려고 합니다.`**
  *'내 안에서 가장 좋은 것을 꺼내다'는 get the best out of 의 축자 번역.*

- [ ] **셰스트룀 `145`**
  현재 `나는 나를 나하고만 비교합니다. 예전의 나보다 나아지고 싶을 뿐입니다.`
  → **`나는 남이 아니라 나하고만 비교합니다. 예전의 나보다 나아지고 싶을 뿐입니다.`**
  *한 문장에 '나'가 셋이라 걸린다. 원문의 대비(myself ↔ 남)도 살아난다.*

- [ ] **매킨토시 `201`**
  원문 `…because that's all I can really control.`
  현재 `나는 늘 나를 더 낫게 만들 방법을 생각합니다. 내가 어떻게 해볼 수 있는 건 그것뿐이니까요.`
  → **`나는 늘 내가 더 나아질 방법만 생각합니다. 내 손으로 어떻게 해볼 수 있는 건 그것뿐이니까요.`**
  *'나를 더 낫게 만들다'는 make myself better 직역. control 의 뉘앙스가 빠져 있다.*

- [ ] **무삼바니 `217`**
  현재 `학교를 마치고 수영을 시작했습니다. 수영장이 없었어요. 아무것도 없었죠. 그래서…`
  → 종결어미를 하나로: **`…수영을 시작했습니다. 수영장이 없었습니다. 아무것도 없었죠.`**
  *한 인용 안에서 습니다/어요/죠 셋이 섞인다. (구어 맛을 남기려면 '없었어요/없었죠'로 통일)*

- [ ] **펠프스 `99`**
  현재 `오늘이 무슨 요일인지도 몰라요. 전 그냥 수영만 해요.`
  → **`오늘이 무슨 요일인지도 모릅니다. 저는 그냥 수영만 합니다.`**
  *4-1 을 적용할 때만. 유일하게 '~요'체다.*

- [ ] **이케에 `188`**
  원문 `悔いのない水泳人生のために、今日も泳ぎ切る`
  현재 `후회 없는 수영 인생을 위해, 오늘도 마지막까지 헤엄칠 것이다.`
  → **`후회 없는 수영 인생을 위해 오늘도 끝까지 헤엄친다.`**
  *`泳ぎ切る`는 '끝까지 헤엄쳐 낸다'는 현재형 다짐이다. '~할 것이다'는 미래 단정이라
  기사 제목의 어조와 다르고, 쉼표도 일본어 원문의 「、」를 그대로 옮긴 것이다.*

- [ ] **밀라크 `272`**
  원문 `I didn't swim for the medal, but for the time.`
  현재 `나는 메달을 위해 헤엄친 게 아니라 기록을 위해 헤엄쳤다.`
  → **`나는 메달이 아니라 기록을 보고 헤엄쳤다.`**
  *'~을 위해 헤엄치다'가 두 번 반복된다.*

- [x] **`calling` `232`** ← 명백한 오역
  원문 `The water is calling, and I must swim`
  현재 `물은 나를 부르고 나는 수영하고 있네`
  → **`물이 부르니 나는 헤엄칠 수밖에`**
  *`must`(당위)를 진행형으로 옮겨 뜻이 바뀌었다. 원문은 존 뮤어의
  "The mountains are calling and I must go" 패러디라 그 리듬을 살리는 편이 낫다.*

- [ ] **`meditation` `238`**
  원문 `Swimming is simply moving meditation`
  현재 `수영은 움직이면서 하는 명상이다`
  → **`수영은 그저 움직이는 명상이다`**
  *`simply` 가 빠졌고, '움직이면서 하는'이 설명조로 늘어진다.*

- `live-love-swim` `244` — 그대로 좋다.
- `chlorine` `250` `락스 냄새는 내 향수` — 그대로 좋다. 동호회에서 실제로 쓰는 말이라
  '염소'보다 낫다.

## 5. 손대지 않아도 되는 것

아래는 읽으면서 확인했고 자연스럽다. 굳이 고치지 않는다.

- 용어집 `short`·`detail` 전체 — 정의문으로서 밀도가 좋다.
- `grading.ts` 의 두 mismatch 안내문.
- `benchmark.ts` 의 `basis` 문장들, `STANDING_BASIS`.
- 지상훈련 `why` 다섯 편.
- 하단 주의문(`index.html:216`), 시작 화면, 식단 출처 문구.
